# The talk

Eleven slides for the four-minute presentation, drawn over a 3D scene. Plain HTML, CSS and WebGL2: no libraries and no build step, like the app.

## Run it

Serve the repository and open `/talk/`:

```bash
python3 -m http.server 8000
```

The app is then at <http://localhost:8000/> and the talk at <http://localhost:8000/talk/>. The talk also opens straight from disk (`talk/index.html`); the button that opens the live app is hidden then. The typefaces come from Google Fonts, and without a network the page falls back to system fonts.

## Keys

| Key | What it does |
|---|---|
| `→` `Space` `Page Down` | next step, then next slide |
| `←` `Page Up` | back |
| `1` to `9`, `0` | jump to slide 1 to 9, or 10 (slide 11 with the arrow keys) |
| `T` | start or pause the clock; `Shift` `T` sets it back to zero |
| `N` | speaker notes on this screen |
| `P` | speaker notes in a second window, which follows the slides |
| `D` | open the live app in a new tab |
| `F` | full screen |
| `R` | put the 3D view back where it was |
| `H` | list of keys |

Drag the scene to look around, scroll to zoom, and point at a column to see its field.

## Where the numbers come from

`data.js` is generated by `build-data.mjs`, which runs the app's own engine (`js/engine.js`) on the app's own data and stops if a number differs from the engine's:

```bash
node talk/build-data.mjs
```

The slides read every figure from that file. The sliders on slide 5 and slide 9 look results up in it, so they give the same answers as the app.
